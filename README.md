# homebrew-tap

A [Homebrew](https://brew.sh) tap for tools by [Mark McDermott](https://markmcdermott.io).

## Install

```
brew install mark-mcdermott/tap/puravida
```

Or tap first, then install:

```
brew tap mark-mcdermott/tap
brew install puravida
```

Upgrade and remove as usual:

```
brew upgrade puravida
brew uninstall puravida
```
